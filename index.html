    Settings

    TMDB API Read Access Token

    From your TMDB API settings, copy the long API Read Access Token — not the shorter API Key, which this app does not use. Stored in this browser only, sent only to TMDB, and never included in Gist sync.

    Collection storage

    Use a throwaway GitHub account with a fine-grained token limited to gist read/write. The token stays in this browser and is never written into the Gist.

    Cache

    Movie data is cached in this browser and refreshed in the background on every visit. Clearing it only costs one slower load.

    About

    Search TMDB, add movies to ordered lists, and browse them as a grid, a list, or a full detail view. Your lists stay in this browser unless you connect Gist sync.

    This product uses the TMDB API but is not endorsed or certified by TMDB.

    Movie metadata and images come from The Movie Database. This project is not affiliated with TMDB.
