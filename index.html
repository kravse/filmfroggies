        Settings

        TMDB API Read Access Token

        From your TMDB API settings, copy the long API Read Access Token — not the shorter API Key, which this app does not use. Stored in this browser only, sent only to TMDB, and never included in Gist sync.

        Collection storage

        Use a throwaway GitHub account with a fine-grained token limited to gist read/write. The token stays in this browser and is never written into the Gist.

        Automatic backups

        A separate private Gist stores up to five snapshots in one file, moviecollector-backups.json. A new snapshot is appended on load when the latest is more than 20 minutes old. Restoring replaces your current lists with the chosen snapshot and syncs that state back to GitHub.

          Cache

          Movie data and poster images are cached in this browser and refreshed in the background on every visit. Clearing it only costs one slower load.

          Repo data

          Movies bundled with the site load instantly and never touch the API. Export this list, commit it to the repo as data/my_list.csv, then run npm run scrape to refresh the bundled copy.

          About

          Search TMDB, add movies to ordered lists, and browse them as a grid, a list, or a full detail view. Your lists stay in this browser unless you connect Gist sync.

          This product uses the TMDB API but is not endorsed or certified by TMDB.
